2. Mobile Animation & Smoothness Architecture
Optimization Domain Previous Bottleneck Engineered Solution Performance Benefit
Hero Parallax RAF Engine Ran 60fps loop continuously even when viewing other sections Added IntersectionObserver; halts RAF completely when hero exits view Zero idle CPU/GPU consumption
Mobile Device Gyroscope Listened to deviceorientation at 60Hz, re-rendering 10 3D layers during scroll Disabled deviceorientation on mobile touch devices; static clean framing Eliminates camera jitter & micro-stutters
Stage Scroll Controller Called getBoundingClientRect() 5 times on every scroll RAF Pre-measures section offsetTop on init/resize; pure arithmetic on scroll Eliminates forced DOM layout reflows
Audio Equalizer Bars Animated height directly (0% { height: 4px; } 100% { height: 14px; }) Replaced with transform: scaleY(0.28) to scaleY(1) GPU compositor thread, zero layout recalculations
Petal Particle Simulation touchmove spawned canvas sparks during every scroll swipe Removed touchmove cursor sparks; reduced mobile particles to 3 petals & 8 motes Buttery smooth 60fps touch scrolling
Scroll Reveal Speed Slow 1.0s entrance transition caused elements to lag behind finger scroll Optimized to 450-550ms with 20px subtle translation and 50-60ms stagger Crisp, immediate feedback (within 400-650ms)
Section Header Halo filter: blur(24px) forced rasterization on every frame Feathered radial-gradient color stops without blur filter Native GPU fillrate optimization
Inactive Scenes Continuous keyframes ran on background scenes not in view Added animation-play-state: paused for .stage-scene:not(.is-active) Conserves battery and GPU memory
